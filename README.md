# Python Password Generator 🔐

## About the Project
A simple password generator built with Python that creates random passwords based on the length specified by the user.

## Features
- Generate random passwords.
- Include uppercase letters and lowercase letters.
- Include numbers and special symbols.
- Validate user input.
- Require a minimum password length of 6 characters.

## Technologies Used
- Python
- `random` module
- `string` module

## Project File
- `Password Generator.ipynb` — The main project containing the Python code.

## How to Run
1. Download or clone this repository.
2. Open `Password Generator.ipynb` using Jupyter Notebook.
3. Run the notebook cells.
4. Enter a password length of 6 or more characters.
5. Copy your generated password.
